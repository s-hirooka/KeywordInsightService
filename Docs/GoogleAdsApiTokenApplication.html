1. Business Overview

S-WORK operates a digital marketing business and uses Google Ads for keyword research, campaign planning, and market analysis. We are developing an internal Windows desktop tool named KeywordInsightService to support our research workflow.

2. Purpose of the Tool

The tool is used only by internal staff to retrieve keyword planning data from the Google Ads API. Its main purpose is to help our team evaluate search demand and competition before planning campaigns and related marketing activities.

3. Google Ads API Features Used

The application uses the Google Ads API Keyword Planning historical metrics endpoint. For a list of user-input keywords, the tool retrieves the following fields:

  • Keyword
  • Average monthly searches
  • Competition level
  • Competition index
  • Low top of page bid
  • High top of page bid
  • Retrieved timestamp

4. How the Tool Works

Platform Windows desktop application built with C# and Windows Forms
Users Internal employees only
Authentication Google Ads API developer token and OAuth 2.0 refresh token
Input User enters one or more keywords, language ID, geo target IDs, and target customer ID
Output Keyword metrics are displayed in a grid, exported to CSV, and optionally stored in a local SQLite database
Storage Local machine only, using SQLite and local cache files

5. Data Usage and Storage

Retrieved keyword metrics are used for internal research, analysis, and planning. The data is displayed in the application UI and can be saved locally in a SQLite database for history tracking and reporting. The application also uses local caching and daily usage limits to reduce unnecessary API calls.

6. What the Tool Does Not Do

  • It does not create ads.
  • It does not modify campaigns, ad groups, or keywords in Google Ads.
  • It does not change bids, budgets, or billing settings.
  • It does not manage payments or perform billing operations.
  • It does not automate ad delivery or ad serving.
  • It does not use Conversion Tracking API or Remarketing API.

7. Intended Access Level Request

We are requesting access beyond test accounts because this tool is intended to retrieve historical keyword planning metrics for production Google Ads accounts that we manage for internal business use.

8. Compliance Statement

This application is designed for internal use only. We will use the Google Ads API in compliance with Google Ads API Terms and Conditions and applicable Google policies. Access is limited to authorized internal users.

Summary: KeywordInsightService is an internal keyword research tool that reads historical metrics from Google Ads API for planning and reporting. It does not create, edit, or serve advertisements and does not perform billing-related actions.
