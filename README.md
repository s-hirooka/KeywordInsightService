# KeywordInsightService

Google Ads APIを利用して、キーワード調査・検索ボリューム取得・関連キーワード分析を行うためのC#ツールです。

PPC広告やSEOのキーワード調査業務を効率化する目的で開発しました。

## What it solves

- Google Ads APIを使ったキーワードデータ取得
- 検索ボリュームの取得
- 関連キーワードの調査
- キーワード調査作業の自動化
- PPC広告・SEO施策の調査時間削減

## Tech Stack

- C#
- .NET
- Google Ads API
- OAuth 2.0
- JSON
- REST API

## Main Features

- Google Ads APIとの連携
- Refresh Tokenを利用した認証
- キーワードデータの取得
- 検索ボリューム取得
- キーワード情報の整理・保存
